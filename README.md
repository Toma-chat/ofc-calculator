# OFC 計算表

スマートフォン・iPad向けの、2人／3人対戦用パイナップルOFC点数計算アプリ。

- BTN・A・Bの対面表で役と勝敗を入力し、自動計算。
- 3人用では各段の順位を指定。同順位は引き分け。
- バストした側の役入力を無効化し、役の点数を除外。
- 上段→中段→下段で役の種類が逆転した場合は「バストしています」と警告し、関係する精算を保留。入力修正またはバスト指定で再計算。
- スクープと各ペアの精算・全員の収支を表示。
- スマホ縦向き、iPad横向きに合わせた配置。通常画面は1ページにまとめ、ルールと詳細はダイアログに表示。
- 履歴・サーバー保存・アクセス解析なし。カード配置の自動判定なし。

小さい画面、横向きスマホ、文字拡大時は、操作を隠さずスクロールできるようにしています。

## 開発

Node.js 20以上。外部パッケージのインストールは不要です。

```sh
npm start
npm test
```

プレビュー: http://127.0.0.1:4173

## 公開

GitHub PagesのSourceを **GitHub Actions** に設定してください。`main`へのpushでテスト後に自動公開します。

## 点数

各段±1点、3段すべて勝利で追加3点。役のボーナスは自分と相手の差分を加算。バストは正常な相手に6点＋相手の役ボーナスを支払い、両者バストは0点。3人では全3ペアの結果を合算します。

一般的なロイヤリティを採用しています。詳細はアプリの「計算ルール」を確認してください。ローカルルールの変更には`scoring.js`を編集してください。

バスト警告は役の種類から確定できる逆転のみを検出します。同じ役の数字・キッカーは比較しません。「なし」は役なしではなくボーナス0点の役（中段はツーペア以下、下段はスリーカード以下）を含むため、誤判定しない範囲で検証します。
